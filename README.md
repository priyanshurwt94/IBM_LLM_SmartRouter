# AI-Powered Intelligent LLM Optimization & Dynamic Fallback Router

## Project Overview
Enterprise systems executing large language model workflows encounter high financial token expenditure and latency spikes during concurrent traffic surges. This system implements an optimized machine learning classification model to audit API endpoint performance profiles and proactively transition workloads to secondary backup routes before high latency impacts the application interface.

## Technologies Utilized
* Core Language Framework: Python 3
* Structural Manipulation: Pandas, NumPy
* Analytical Visualizations: Matplotlib, Seaborn
* Predictive Modeling Subsystems: Scikit-Learn Ecosystem

## Execution Steps
1. Place the Kaggle dataset tracking sheet inside this workspace folder and rename it to `llm_price_performance_tracker.csv`.
2. Install all library frameworks using the terminal command:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the primary data operation script:
   ```bash
   python PriyanshuRawat_LLM_SmartRouter.py
   ```
